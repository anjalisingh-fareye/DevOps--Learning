12 August 2026

Understand the fundamentals of Linux and the Linux Shell.

- History of Linux

- Linux Distributions

## Commands Practiced
```bash
pwd
ls
cd
mkdir
touch
cp
mv
rm
clear
whoami
hostname
date
```

## Hands-on
- Navigated directories using `cd`
- Created files and folders using `mkdir` and `touch`
- Listed files using `ls`
- Checked current working directory using `pwd`
- Removed files using `rm`

- Practiced creating, deleting and managing files/directories.
